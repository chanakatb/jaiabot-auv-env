Reward Function:
total_reward = (3.0 * goal_reward +           # Primary: reach goal  -> Exponential reward for getting closer to the goal. Max reward when at goal, decays as distance increases.
               2.0 * heading_reward +         # Secondary: point toward goal -> Rewards pointing toward the goal, but only when far away. Prevents spinning near the goal.
               2.0 * speed_reward +           # Critical: correct speed -> Massive rewards for your robot's operating speeds (0.5-1.2 m/s).
               0.5 * forward_reward +         # Movement encouragement -> Encourages forward motion up to 1.2 m/s
               speed_penalty +                # Speed safety -> Strong deterrent against unrealistic speeds for your robot.
               action_penalty +               # Efficiency -> Small penalty for using large control inputs.
               spinning_penalty +             # Anti-spinning -> Prevents excessive spinning and circular motion.
               efficiency_reward +            # Straight-line bonus -> Rewards moving in a straight line toward the goal.
               rudder_penalty +               # Smooth control -> Small penalty for excessive rudder use
               completion_bonus)              # Goal completion -> Large bonus for actually completing the task
               
               
Train: 
Using the parallel training, the number of 2048 Jaiabots are used to train simultaneously.Each Jaiabot get a target position in the range of 18-20 meters and needs to reach there withing 50 seconds. Assume all the Jaiabots are only operating on the surface.  Each robots may have the different initial conditions. 
Right now, this training does not include water current or drift. Looking at your code, there are no environmental disturbances modeled. I am planing to implement this into dynamic environment later, hopefully, after a full field test with this results. 

What I did is I used the existing 3D CUREE is an AUV equipped with 6 BlueRobotics T200 thrusters for 6-DOF, and change and add the configuration parameters (weight, length, width, height, number of thruster, one rudder) to match with the Jaiabot. With this modification, the simulator does not show the correct robot and the hydrodynamic forces may slightly differ. I wanted to check my codebase being trainable and testable.
